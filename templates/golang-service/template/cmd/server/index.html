Start developing

  1. Clone the repository 
    git clone {{ .Links.Repository }}.git
  2. Run it locally on localhost:8080; make test runs the tests. 
    make run
  3. Add your first route in cmd/server/main.go, with a pattern like GET /orders/{id}, and list it in endpoints so it shows up below. It gets metrics and access logs without any extra code.
  4. Push to main. CI tests it and builds the image; the platform deploys that exact commit to dev on its own, usually within a minute or two. Promoting to prod is one action in the developer portal.

What the platform gives you

Continuous deployment

Every green build on main reaches dev automatically, as a Git commit you can read and revert.

Public HTTPS endpoint

This address, its DNS record and its TLS certificate are created from the deployment, per environment.

Safe rollouts

Two replicas, readiness checks, and rollouts that never drop below full capacity; node drains evict one pod at a time.

Metrics

Request rate, errors and latency per route, plus runtime metrics, scraped by Prometheus with no setup.

Structured logs

One JSON line per request on stdout, ready for any log collector.

Databases on request

Ask for a database in the portal; its connection details are mounted into the pods for you.
